# AI-SafeStep
SafeStepAI detecta en tiempo real hasta 80 tipos de objetos con YOLOv8, calcula su posición y distancia, y los narra en voz alta en español (gTTS). Funciona con cámara web, imágenes o video. Busca dar mayor autonomía a personas con baja visión, actuando como un guía sonoro de su entorno.
